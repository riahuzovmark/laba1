# Лабораторна робота № 2. Цикли, функції та налагодження

## Варіант 19. Модулі й підсумковий тест

### Призначення програми
Програма послідовно читає N записів студентів (кількість завершених модулів та бал за підсумковий тест), перевіряє коректність вводу, обчислює загальний показник m, визначає категорію, перевіряє умову пошуку та формує підсумкову статистику без збереження записів у контейнері.

### Поля, межі та одиниці
- N (int): кількість записів, 1..30
- modules (int): завершені модулі, 0..5
- test (int): бал за тест, 0..50

### Формула та правила
- Показник: m = 10 * modules + test (0..100)
- Категорія (послідовно):
  1. якщо modules < 2 - недостатньо модулів
  2. інакше якщо m < 60 - потрібне доопрацювання
  3. інакше - умовний успішний результат
- Пошук: modules >= 2 && m >= 60

### Збірка та запуск
У Visual Studio: відкрити проєкт і натиснути Ctrl + F5 (або F5 для налагодження).
У терміналі: g++ -std=c++17 Laba2.cpp -o app та запустити .\app.exe

### Опис тестів і призначеного дефекту
Програму перевірено на 10 обов'язкових сценаріях (N=1, стандартний набір N=3, межі полів і пороги, нічия min/max, немає збігів, усі збіги, збіг до кінця потоку, повтор запису при помилці межі, помилка формату та EOF).
У проєкті Laba2_DefectD3 відтворено та виправлено призначений дефект D3 (у функції isEligible замінено строге порівняння > на включне >=).
