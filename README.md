# ЛБ1 — Лінійні та розгалужені алгоритми

* **Дисципліна:** Основи програмування
* **Група:** ІІТ-26-1
* **Варіант:** Варіант 19. Бали за завершені модулі та підсумковий тест
* **Мова/стандарт:** C++

---

## Призначення

Програма призначена для розрахунку загальної суми балів студента за завершені навчальні модулі та підсумковий тест. Програма перевіряє коректність введених даних, обчислює бали за модулі (по 10 балів за кожен модуль) та загальний результат, після чого визначає статус складання за умовним алгоритмом.

---

## Вхідні дані та правила

### Вхідні змінні:
* `modules` (`int`) — кількість завершених модулів. Допустимі межі: [0, 5].
* `test` (`int`) — бали за підсумковий тест. Допустимі межі: [0, 50].

### Формули розрахунку:
* `modulePoints = modules * 10`
* `total = modulePoints + test`

### Порядок перевірок та умов:
1. **Валідація типу даних:** Перевірка, чи введено саме цілі числа. Якщо ні — виводиться *"Неправильне введення"*.
2. **Перевірка меж:** Перевірка умов `modules < 0 || modules > 5 || test < 0 || test > 50`. Якщо значення поза межами — виводиться *"Помилка: Значення виходять за допустимі межі."*.
3. **Визначення статусу:**
   * Якщо `modules < 2` — виводиться *"недостатньо завершених модулів"*.
   * Інакше, якщо `total < 60` — виводиться *"потрібне доопрацювання"*.
   * Інакше — виводиться *"умовний успішний результат"*.

## Збірка та запуск

1. Відкрийте файл розв'язку проєкту (`.sln`) у середовищі **Visual Studio**.
2. Переконайся, що обрана конфігурація **Debug** або **Release** та платформа **x64** (або **x86**).
3. Зберіть проєкт за допомогою комбінації клавіш `Ctrl + Shift + B` (або `Build -> Build Solution`).
4. Запустіть програму без налагодження, натиснувши `Ctrl + F5` (або `Debug -> Start Without Debugging`).
